# Requirements

The following packages need to be installed on Arch Linux before running the Archzen script:

- base
- base-devel
- linux-firmware
- sof-firmware
- sudo
- bash
- mkinitcpio
- networkmanager
- dhcpcd
- wpa_supplicant
- reflector
- pacman-contrib
- git
- curl

These packages are typically included in a basic Arch Linux installation or can be installed using pacman.
